# JAARVIS — live voice from your browser

Hold TALK, speak, release. The brain runs here on the server (Gemini Live);
your mic audio never leaves this session except to the model, and the API key
stays in Space Secrets (`GEMINI_API_KEY`).

Souls: Jarvis / Friday / Ultron. Desktop app (face + system control) in the repo root.
